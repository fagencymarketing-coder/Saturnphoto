# Сатурн — фотографии для сайта

Только изображения для sssaturn.ru. Код, данные каталога, документы и логотипы — в репозитории [Saturn](https://github.com/fagencymarketing-coder/Saturn).

| Папка | Что внутри |
|---|---|
| `tilda-photos/` | фото для импорта каталога в Tilda, по одному на товар, имя = SKU |
| `product-photos/` | исходные фото товаров по производителям и вырезанные на прозрачном фоне (`_cutout/`) |
| `crop-photos/` | фото культур и сортов; источники и лицензии — в `crop-photos/README.md` |
| `catalog-images/` | картинки карточек каталога по брендам |
| `scene-photos/` | фото для фоновых блоков |

Прямая ссылка на файл:
`https://raw.githubusercontent.com/fagencymarketing-coder/Saturnphoto/main/<папка>/<файл>`

Репозиторий публичный намеренно: Tilda при импорте забирает фото по прямым ссылкам.
